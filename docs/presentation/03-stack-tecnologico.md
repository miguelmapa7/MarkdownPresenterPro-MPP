# Stack Tecnológico

## Frontend

- **React 18** — Biblioteca de UI con componentes declarativos
- **TypeScript** — Tipado estático para contratos entre capas
- **Tailwind CSS** — Estilos utility-first para diseño rápido
- **Framer Motion** — Animaciones fluidas a 60fps

## Desktop

- **Tauri 2.0** — Framework de escritorio con backend en Rust
  - Binarios 90-97% más pequeños que Electron
  - Menor consumo de memoria
  - Sistema de permisos por seguridad

## Procesamiento de Markdown

- **Unified.js** — Ecosistema de procesamiento basado en AST
  - `remark-parse` → Markdown a AST
  - `remark-gfm` → Soporte GitHub Flavored Markdown
  - `rehype-highlight` → Syntax highlighting
  - `rehype-stringify` → AST a HTML

## DevOps

- **Docker** — Contenedorización multi-stage
- **GitHub Actions** — CI/CD automatizado
- **Husky + lint-staged** — Pre-commit hooks
