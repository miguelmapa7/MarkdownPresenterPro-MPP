# Markdown Presenter Pro

## Visión del Proyecto

MPP es una aplicación de escritorio que transforma archivos Markdown en presentaciones interactivas y profesionales.

A diferencia de herramientas como PowerPoint o Google Slides, MPP está diseñada para desarrolladores y personas técnicas que ya escriben en Markdown.

### Características principales

- Renderizado fiel de Markdown (CommonMark + GFM)
- Navegación dual: lineal + menú flotante tipo Dock
- Modo Presentador con cronómetro
- Multiplataforma: Windows, macOS, Linux
